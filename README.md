# tzofia-eye
אתר המנהל התראות המגיעות לאזורים שונים בישראל, עם אפשרות להוספת עריכת ומחיקת התראות, והצגתם על המפה.

משתמש ב:
nodeJS, express, react + TS, vite, mongoDB.

## db

על אף שהנתונים כרגע עם מבנה קשיח ולא ניתן לשינוי, והבחירה ההגיונית והפשוטה הייתה לבחור במסד נתונים sql/supabase ודומיו,

עם זאת בחרתי להשתמש במסד נתונים גמיש - mongoDB, מכיוון שכרגע אין לי את כל המידע על המבחן - איזה שדות יהיה עליי להוסיף, באיזה תנאים וכו, ובמונגו יהיה קל יותר לבצע שינויים.

המסד מכיל אוסף אחד של מסמכים - alerts, שהמבנה שלהם מוגדר ומאומת ב zod, למניעת הזרקת שדות לא מבוקשים, ולווידוא סוגי נתונים שנכנסים.

## status codes
השתמשתי בerror handler כ middleware, 
כש 404 מתאר alert not found,
400 מתאר הכנסת נתונים שגויה,
ו500 מתאר שגיאה בשרת.
